# U-BASE Recruitment Intelligence

HTML5 · CSS3 · Vanilla JavaScript 기반 채용 통합관리 웹입니다. 백엔드, 서버, 외부 API, CDN 요청을 사용하지 않습니다. XLSX 라이브러리와 라이선스는 `vendor/`에 포함되어 있습니다.

## 실행

폴더 구성을 그대로 유지한 상태에서 `index.html`을 Chrome 또는 Edge로 여세요. 브라우저 정책이 로컬 파일 실행을 차단하는 경우 로컬 파일 접근이 허용된 브라우저 환경이 필요합니다. 별도 서버를 설치하거나 실행할 필요가 없습니다.

데이터 관리에서 채용마감현황, 지원자통합조회, 입사자퇴사자조회, 광고비 XLSX를 각각 선택하고 컬럼을 확인한 후 등록합니다. 필요한 컬럼은 별표로 표시됩니다. 여러 시트는 선택한 시트만 등록하며, 다른 시트를 추가하려면 누적 모드로 재등록합니다. 처음에는 데이터가 없고 가상 데이터는 제공하지 않습니다.

데이터는 현재 브라우저의 IndexedDB에 저장됩니다. 브라우저/프로필/파일 위치를 변경하면 저장소가 달라질 수 있으며, 시크릿 모드나 브라우저 데이터 삭제 시 소실될 수 있습니다. 전체 백업 JSON을 정기적으로 저장하세요. 복원은 데이터와 목표 전체를 교체하며 확인 후 적용합니다. 백업에는 집계에 필요한 식별번호와 조직/직무/매체가 포함되므로 취급에 유의하세요. 성명, 주민등록번호, 전화번호, 주소 등의 불필요한 개인정보 컬럼은 읽은 후 저장하지 않습니다.

## 집계와 필터

- 채용요청·지원자: 최종면접일. 입사자: 입사일. 광고비: 집행일. 시작일·종료일 모두 포함합니다.
- 기준일이 없거나 잘못된 행은 전체 기간에서도 제외하며 누락 건수를 표시합니다.
- 채용요청건수는 채용공고번호가 있는 행 수. 입사요청인원·면접요청인원은 각각의 컬럼 합계입니다.
- 서류접수는 이력서번호가 있는 행 수. 서류합격은 서류심사결과가 정확히 ‘합격’인 행 수입니다.
- 면접참석은 면접결과 ‘합격’ 또는 ‘불합격’, 면접합격은 ‘합격’인 행 수입니다.
- 입사자는 기간과 필터에 해당하는 행에서 사번별 고유 인원을 집계하며 퇴사자를 제외하지 않습니다.
- 입사율 = 입사인원 ÷ 면접합격 × 100. 분모 0은 ‘—’입니다.
- 파일 안의 중복 식별번호는 경고만 표시하고 행 수 규칙을 유지합니다. 입사자는 사번을 중복 집계하지 않습니다. 누적 등록 시 기존 데이터와 모든 연결 컬럼이 동일한 행은 재등록하지 않습니다. 원본 내부의 서로 다른 행은 유지합니다. 동일 식별번호의 변경 데이터를 수정하려면 해당 유형 교체를 사용하세요.
- 숫자 누락/오류는 별도 알림을 표시하며 해당 셀을 합계에 더하지 않습니다. 누락/오류가 있으면 원본 또는 컬럼 연결을 확인하세요.
- 센터는 `팀/센터명`, `TF/센터명`에서 조직 접두사를 제거합니다. 지원자·입사자는 채용공고번호가 연결되고 요청 직무가 단일한 경우 요청 파일의 직무형태로 통일합니다. 연결되지 않거나 직무가 모호하면 원본 직무를 유지합니다. 입사자 유입채널이 코드로 제공되어 지원자 매체명과 다를 경우 데이터 관리의 ‘매체명·유입채널 코드 연결’에서 실제 분류표에 맞춰 지정하세요. 원본 코드를 추정 변환하지 않습니다. 연결 설정도 백업에 포함됩니다. 광고비의 센터·직무·매체는 다른 파일과 동일한 분류로 입력해야 함께 분석됩니다.
- 단계별 실적은 서로 다른 기준일을 사용합니다. 동일 지원자 코호트의 전환율이 아니며 비율이 100%를 넘을 수 있습니다.
- 광고비는 광고비 파일만 사용합니다. 요청 파일의 ‘사용광고비’를 다시 합산하지 않습니다. 비용은 필터별 광고비 ÷ 해당 지원/입사 인원이며, 미등록은 ‘미등록’, 분모 0은 ‘—’입니다.

## 보고서와 목표

목표는 기간·센터·직무·매체 필터 조합별로 저장합니다. 보고서에서 Excel을 다운로드하거나 PDF 저장/인쇄를 누른 뒤 브라우저 인쇄 창의 ‘PDF로 저장’을 선택하세요. Excel에는 요약·센터별·매체별·필터 시트가 포함됩니다. 개인정보 원본은 보고서에 포함되지 않습니다.
